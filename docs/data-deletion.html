Petunjuk Penghapusan Data Pengguna

Terakhir diperbarui: 5 September 2026

Aplikasi "Auto Poster Kisah Nabi" tidak menyimpan data pribadi pengguna Facebook lain di server atau database eksternal manapun. Aplikasi ini hanya digunakan oleh satu pengembang untuk mengelola satu Halaman Facebook miliknya sendiri.

Jika Anda ingin data akses (token) yang terkait dengan akun Anda dihapus dari aplikasi ini:

  1. Kirim email ke joni.hermawan04@gmail.com dengan subjek "Hapus Data - Auto Poster Kisah Nabi"
  2. Sertakan nama akun Facebook Anda
  3. Permintaan akan diproses dalam 7 hari kerja

Anda juga dapat mencabut akses aplikasi ini kapan saja melalui pengaturan Facebook Anda di Pengaturan > Aplikasi dan Situs Web.
