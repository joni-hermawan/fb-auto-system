Kebijakan Privasi

Terakhir diperbarui: 5 September 2026

Aplikasi "Auto Poster Kisah Nabi" adalah alat otomasi pribadi yang digunakan untuk menghasilkan dan mengunggah video edukasi cerita Islami ke satu Halaman Facebook yang dikelola sendiri oleh pengembang.

Data yang Diakses

Aplikasi ini hanya mengakses:

  • Daftar Halaman Facebook yang dikelola oleh akun pengembang (pages_show_list)
  • Data engagement dasar dari Halaman tersebut (pages_read_engagement)
  • Kemampuan untuk membuat postingan video di Halaman tersebut (pages_manage_posts)

Data yang TIDAK Dikumpulkan

Aplikasi ini tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna lain. Tidak ada database eksternal yang menyimpan data pengguna Facebook. Semua proses berjalan secara lokal atau melalui GitHub Actions milik pengembang sendiri.

Penggunaan Data

Token akses yang diperoleh hanya digunakan untuk mengunggah video ke Halaman Facebook milik pengembang sendiri, dan disimpan sebagai secret terenkripsi di GitHub Actions.
